# Security

Please report a vulnerability privately by email to security@arcade.dev rather than in a
public issue or pull request. Include what you found, how to reproduce it, and the commit
or site page it affects.

This is a community project, so there is no response-time commitment.

The scanner runs the MCP servers and framework adapters you point it at on your own
machine. Treat a server or adapter you do not trust as you would any other code you run.
